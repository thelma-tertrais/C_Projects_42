**Description**
The Libft project consists in learning how to created a personnal libray, a Makefile and this Readme file. We had to recode standard C functions from scratch, using the man. The basic functions are then used to create more complex ones. The projects also introduces new concepts like Structures and Linked Lists.

**Instructions**
Using a Makefile to compile the library libft, with the following instructions: make (compile), make clean (remove .o files), make fclean (remove .o and libft.a), make re (compile everything from scratch). We compiled with the flags: cc -Wall -Wextra -Werror.
